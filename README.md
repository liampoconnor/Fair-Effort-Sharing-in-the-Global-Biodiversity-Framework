# Fair effort sharing under the Global Biodiversity Framework

An interactive tool accompanying *Fair Effort Sharing in the Global Biodiversity
Framework: A Model for Assessing Fair and Proportional Contributions*.

**Live version:** https://USERNAME.github.io/REPONAME/

## What it does

Effort under the Global Biodiversity Framework is treated as a claims problem:
a fixed pool to be divided, and several competing bases on which a country might
be said to owe a share of it. The tool applies weighted proportionality, so a
country's share is

    a_i = E * sum_k w_k * ( x_i^k / sum_j x_j^k )

for pool `E`, basis `k`, weight `w_k` and country indicator `x_i^k`. Shares are
linear in the weights, which is why reweighting shows up as countries changing
rank rather than as curvature.

Three pools can be divided:

| Target | Pool | Quantity |
|---|---|---|
| Target 19 | Biodiversity finance | $200 bn per year |
| Target 3  | Ecosystem protection | 18,924,821 km² of shortfall, costed at $1,478/km²/yr |
| Target 16 | Sustainable consumption | 31,894 Mt of raw material consumption (illustrative) |

Weights can be placed on capacity (GDP), current impact, cumulative impact,
population, and, for Target 3, protection shortfall. Two further switches change
how responsibility is attributed: counting only the portion of a country's
consumption footprint falling overseas, and applying a development floor that
discounts the capacity component below an HDI threshold.

The tool is not prescriptive. No weighting here is defended as the correct one;
the point is to make the consequences of choosing one visible.

## Views

- **Map** — share of the pool by country.
- **Table** — the twenty-five largest shares, with allocations.
- **Continuum** — one country's share swept between any two bases, against its
  nearest neighbours, showing where ranks cross.

## Running it

Everything is computed in the browser from precomputed country indicators, so
there is no server component. To run locally:

    python3 -m http.server 8000

then open http://localhost:8000. Opening `index.html` directly from the file
system will not work, because the browser blocks the data files from loading.

## Files

- `index.html` — the entire application, including all logic and styling
- `data.json` — country indicators and pool definitions (195 countries)
- `world.geojson` — simplified country boundaries for the map

`data.json` and `world.geojson` are generated by `R/27_export_tool_data.R` in the
analysis repository; they are committed here so the tool runs on its own.

## Sources

Country boundaries from Natural Earth. Indicator sources, the derivation of each
pool, and the treatment of countries with missing data are described in the
methods section of the paper.
